# Scotch distillery kind cleanup

Date: 2026-10-21

## Scope

The [pronunciation backfill](./2026-10-21-scotch-distillery-pronunciations.md) found 116 production Entities stored with kind `distillery` and country Scotland that are not Scottish whisky production sites. A read-only dry run proposed an action for each one from its Bottle use (live `GET /v1/bottles?brand=|distiller=|bottler=` counts) and web evidence. The owner approved four groups; the rest are held below.

Bottles columns are counts of Bottles that use the Entity as brand / distiller / bottler.

## Sources

Evidence links are per row. Bottler and brand judgments rely mostly on producer and bottler sites, retailer and auction listings, and specialist databases. Whiskybase blocked fetching, so a few judgments rest on search summaries.

## Decisions

- Changed kind only where confidence was high or medium. Every changed Entity had a null status, so no status became invalid. A kind change does not change Bottle names or links.
- Anonymous label wording and stand-in names (for example A Highland Distillery and Secret Speyside Malt) became `brand`, which matches how Peated stores similar labels such as E1330 and E1331. Rule 4 of the [identity model](../../architecture/whisky-identity-model.md#who-is-the-brand-series-and-bottler) may instead make the bottler's label the Brand; that is a Bottle-level follow-up.
- Peated has no England country, so English firms use United Kingdom.
- Merged only the four high-confidence duplicates. The survivor is the older ID in each case.
- Deleted only Entities with no Bottles and no owned Entities, checked immediately before each delete. Each deleted record was saved in the change log by the delete route.

- Compass Box product names stored as Entities (The Circus, Enlightenment, Magic Cask, Menagerie, Phenomenology, Rogues' Banquet, The General) each carry a Bottle that likely duplicates a Compass Box Bottle. Cladach and Velvet Fig have the same pattern under Special Releases and Wemyss Malts.
- The Single Cask Ltd. (E6078) is Brand on 33 Bottles while its Brand Entity E366640 is Brand on 33 others.
- Williamson (E478) and Speybridge (E4022) are stored as distiller on Bottles, but they are label names, not producers. James Eadie (E5972) is a second distiller on Bottle 44308.
- Official Chivas Regal Bottles 2392, 2750, and 9728 list a bottler, which an official release should not have.
- Isle of Jura 10 (Bottle 447) lists Cane And Grain as bottler, and Spirit of Freedom (E14107) lists Springbank as bottler.
- Indri Bottle 58178 should use Indri (E29374) as distiller instead of Piccadily (E29375).
- The three Glenrinnes Bottles are SMWS GN codes, which are gins.
- Badachro Distillery (E365859) likely duplicates E5463, and Redwood Empire Distilling (E367248) may be the Graton site (E29373).
